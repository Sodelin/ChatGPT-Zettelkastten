# Descriptive title

- ID: stable unique ID
- Date / contributor: UTC date and actual author
- Status: rough question / hypothesis / sourced synthesis / tested result / checked proof

Write the useful idea or question in plain language. Include a source link or say how it arose. An unfinished capture can stop here.

When useful, add:
- Assumptions and scope.
- A related note, with the relation explained in a sentence.
- Contrary evidence or a counterexample.
- What would distinguish this idea from alternatives.
- The next useful action and its current status.

Keep sources and decisive conditions next to the claim. Record the actual validation artifact when calling something tested or formally checked.
